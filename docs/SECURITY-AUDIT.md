## 仍需平台操作或后续验证

### 固定两人注册设置

2026-09-26 读取 Supabase Auth settings 时 `disable_signup` 为 false。用户已明确选择「暂时保留，稍后处理」。当前保持注册设置不变；行级权限阻止无空间成员资格的人读取记忆。以后收紧账号注册时，在 Authentication → Sign In / Providers 关闭 Allow new users to sign up。

### 正式部署与 HTTPS

新界面尚未发布到正式域名。2026-09-26 对现有域名的 HTTP 检查仍返回 200，未强制跳转 HTTPS，未提供新禁止索引响应头。需完成新部署及 Cloudflare HTTPS 设置与旧缓存清理，并重新做外网验收。

### 备份

当前未验证账户的后台备份计划，未执行数据库和照片的完整恢复演练。免费计划默认不包含自动备份；数据库备份不替代照片文件备份。操作安排见 [部署与成本](DEPLOYMENT.md)。

### 存储清理的网络中断

数据库与对象存储分属两个服务，不能由单一前端事务同时完成删除。现在删除照片可安全重试；删除整条记忆前会刷新照片路径，云端清理不完整时会明确提示。若删除后断网或另一端恰在删除期间上传，仍需检查残留对象；本次未引入收费定时服务或后台清理任务。
