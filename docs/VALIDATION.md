## 动效补充验收

- 添加导航高亮移动、内容进入视野时的短暂浮现、卡片悬停、按钮按压、弹窗与照片过渡，以及登录页纸张的有限次轻摆。
- 使用原生 CSS、IntersectionObserver 和 Web Animations API，不添加动画库，不等待退出动画后再切页；浮动按钮和导航的定位容器不参与位移动画。

- 在动画播放期间启用系统减少动态效果，两种屏幕下正在运行的动画均归零。
- 更新后类型检查与静态构建通过；产物约 487 KiB，JavaScript gzip 合计约 104 KiB。数据、云端配置和部署费用均未改变。
