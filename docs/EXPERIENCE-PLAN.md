# 下一轮体验设计：两个人的手帐收藏册

用户已选择纸张、贴纸、日期印章的手帐方向。登录页及登录后的首页、时间轴、回忆、足迹、双人空间和详情页已完成第一轮手帐视觉改版。下文保留后续体验建议，未列入已完成项的能力仍属提案。

## 主要问题

- 手机登录沿用桌面介绍区在前、表单在后的顺序，首屏无法直接完成登录。已改为紧凑品牌栏和表单；320 × 568 到 430 × 932 的模拟视口中，手帐版提交按钮底边约为 500–517 像素，首屏可见。
- 暖色和留白已有一致性，但各页面卡片外观雷同，缺少主角和节奏。大标题占据注意力，真实照片与双人内容的比重不足。
- 记录较少时，固定的去年今日、月份等模块制造空白。展示顺序应适应实际内容，不用虚构记录填充界面。
- 发布记录要填写信息、单独上传照片，手机上缺少随手保存一句话的轻量入口。

## 设计基调

奶油纸色打底，苔绿用于操作，砖红用于日期印章；蓝色和绿色用于区分两人的批注，仍同时显示名字，不仅依靠颜色。正文保持清晰的系统字体，小标题可以使用现有衬线字体。贴纸和胶带只标记照片、月份或收藏，不覆盖文字和按钮。

每屏只突出一个内容焦点。照片保持真实比例或提供完整查看，不能为了拼贴永久裁剪原图。纸张纹理与印章优先用 CSS 或本地 SVG，实现细节不增加远程字体和动画服务依赖。

## 模块变化

| 模块 | 建议内容与形式 | 手机优先原则 |
| --- | --- | --- |
| 今天 | 日期印章、最新照片拼贴、两人最近的各一句话、记录入口 | 首屏能看到真实内容和记录按钮 |
| 时间轴 | 月份分隔页、日期沿线、照片与文字自然交错 | 单列连续阅读，取消大面积空装饰 |
| 回忆 | 有内容的主题收藏、随机明信片；去年今日仅在有记录时突出 | 卡片可读，加载失败可原地重试 |
| 足迹 | 地点索引、地点对应的照片与记忆，形成旅行手帐 | 不用加载重型地图就能浏览地点 |
| 我们 | 双人资料、真实共同记录数量，可选纪念日、封面 | 不默认推算恋爱起始日，不展示虚构统计 |
| 记忆详情 | 同一天两个人的并列或交错批注、照片注释 | 手机顺序清晰，编辑归属明确 |

## 操作和动效

- 记录流程先聚焦文字与照片，其余字段可展开。支持保存前预览、上传进度、失败重试；草稿持久化需处理账号隔离和退出清理。
- 密码显示切换已加入；下一轮继续验证软键盘、小屏幕、横屏和长文字。
- 动画围绕动作：翻一张回忆卡、照片轻轻落下、保存后日期印章出现。保持短促，系统减少动态效果时停用；导航不等待动画。
- 加入收藏或主题需要设计数据结构和权限，再做界面，不以无实际作用的按钮充数。

## 实施顺序与验收

1. 首页和记忆卡片：先形成一套完整样式，至少检查 0、1、多条记录及有无照片的状态。
2. 手机记录流程和详情：验证两人分别编辑、草稿隔离、图片上传失败重试。
3. 时间轴与回忆：验证不同数量内容、快速翻页、照片链接更新和减少动态设置。
4. 足迹和双人空间：复用统一样式，并按真实需求加入纪念日和收藏数据。

保持 Cloudflare Pages 静态托管及现有 Supabase 架构。视觉改版本身无需付费服务；若后续生成旧照片缩略图，需要核算存储和出口，保留原文件，确认恢复方案后另行实施。

## 2026-09-26 本轮完成

- 首页增加收藏册封面式标题、真实记录数印章、日期卡、相纸边框与胶带、双人便签。时间轴采用横线纸，回忆采用相片卡和随机明信片。去年今日在没有记录时隐藏。
- 新增和编辑记录复用城市选择器，支持中文/英文名称搜索、具体地点补充，新建时也可使用最近记录的地点。移除原始经纬度表单；天气、音乐和备注收进可展开的细节区。
- 预置城市中心来自 GeoNames，出处及许可见 THIRD-PARTY-NOTICES.md。任意自定义地点可保存，但不猜测位置；城市标记明确是大致位置。
- 保留已有明确坐标。没有坐标的记录按完整城市名称或“城市 · 地点”推导城市位置，新建仍使用现有原子保存流程，不需要 SQL 迁移。更改编辑地点时清除上个地点的坐标。相同城市中心的记忆在足迹中合并。
- 无地图 API、远程字体或新运行时依赖；仍为 Cloudflare Pages 静态部署。
- 地点逻辑加入单元回归；浏览器回归覆盖 320/390/820/1440 宽度、新增/编辑请求、清空旧位置以及布局溢出。写请求被测试拦截，不改动现有记忆。

## 足迹页：旅行手帐

- 大幅缩小原来的方位示意，以真实照片拼贴、城市明信片、日期范围、心情摘录和记忆目录组成主要内容。统计均来自当前空间的真实记录。
- 城市标签切换收藏页。南京、南京市以及“南京 · 玄武湖”等按同城展示，旧坐标差异不再拆成重复城市；只改变展示分组，不更新数据库的位置。
- 没有坐标的自定义地点也参与展示，完全未填地点的记录保留在“待补充地点”。没有照片时展示文字页和补照片入口，空空间有第一条记录入口。
- 每次只为所选地点的前 3 张照片获取访问链接，足迹未激活时不额外加载照片；快速切换有请求版本保护，沿用照片失败重试组件。
- 本地浏览器验证真实照片、详情跳转及 320/390/820/1440 排版；只读模拟数据验证多城切换、同城合并、无照片、自定义地点、未填地点和完全空白状态。
